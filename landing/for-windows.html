Frequently Asked Questions

Everything about running Terse on Windows.

Is Terse available for Windows?
Yes. Terse for Windows is a full Tauri port sharing the same frontend as the Mac app: optimizer, agent monitoring, budget circuit breaker, Terse Doctor, Farm, pets, and island. It is not a cut-down companion app.
How does Terse capture text on Windows?
Via terse-uia.exe, a helper built on the Windows UI Automation API. It reads the focused text field in any app and can replace your draft with the optimized version in place — mirroring the Swift accessibility helper on macOS.
Do I need WebView2?
Terse's UI runs on Microsoft WebView2, preinstalled on Windows 11 and most updated Windows 10 systems. The installer bundles the runtime offline so it works either way, and shows a clear error instead of failing silently if the runtime is missing.
Is there feature parity with macOS?
Yes — same frontend, ported Rust backend. Optimizer, capture/replace, agent monitoring, breaker, Doctor, Farm, pets, and island all work on Windows. Only the platform plumbing differs: UI Automation instead of the macOS Accessibility API.
Which agents are monitored on Windows?
The same 8 as macOS: Claude Code, OpenClaw, Aider, Cursor Agent, OpenAI Codex, GitHub Copilot CLI, Cline, and Windsurf. Claude Code has the deepest integration with exact token counts from JSONL streaming.
How is it installed?
An NSIS installer with a per-machine install — Terse lands in Program Files like a normal Windows application and works across user accounts. A 30-day free trial starts on first launch; everything runs on-device.
