Frequently Asked Questions

Everything about using Terse with OpenClaw.

How does Terse detect OpenClaw?
Via process and configuration detection — one of 8 agents recognized out of the box, no OpenClaw config changes. Sessions appear in the monitor with token usage, estimated cost, burn rate, and history.
Can I set a spending limit for OpenClaw?
Yes. Set a burn-rate, token, or dollar ceiling in the budget circuit breaker. On breach, Terse escalates alert → SIGSTOP pause → SIGTERM kill before the next API call, with one-click resume.
Why do always-on agents need a budget guard?
An agent that runs 24/7 can loop or misfire while you're away — burning tokens for hours unnoticed. Terse watches burn rate continuously and enforces your ceiling at the process level, so unattended never means uncapped.
Does Terse compress the prompts I send OpenClaw?
Yes — the 35+ technique pipeline runs in Light, Balanced, or Aggressive mode, with code blocks, paths, and identifiers always protected. Typical reduction is 40–70%.
Is OpenClaw monitoring as deep as Claude Code?
No — Claude Code gets exact tokens, cache efficiency, and 30-day backfill via JSONL streaming. OpenClaw gets process/config detection with session-level stats and estimates. Optimizer, Doctor, and breaker work fully for both.
Does any OpenClaw data leave my machine?
No. Detection, monitoring, compression, and budget enforcement all run on-device on macOS or Windows.
