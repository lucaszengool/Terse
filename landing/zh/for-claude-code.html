常见问题

关于在 Claude Code 中使用 Terse 的一切。

Terse 如何降低 Claude Code 的 token 成本?
Terse 通过进程扫描自动检测 Claude Code,并附加一个悬浮优化器。它压缩每条提示词(去除赘词、错别字、冗余),检测重复工具调用,标记冗余文件读取,并实时跟踪每轮开销。一次典型的 2 小时会话中,总 token 用量可下降 40–89%。
Terse 能自动配合 Claude Code 工作吗?
可以。Terse 每 5 秒扫描一次运行中的进程,Claude Code 一启动就会被自动识别。悬浮监控条会出现在终端上方,无需任何设置。
什么是 CLAUDE.md 规则生成?
监控完一次会话后,Terse 会分析其中的模式——重复的工具调用、常见的提示词结构、冗余的上下文——并生成 CLAUDE.md 规则。把这些规则放进你的项目,Claude Code 在之后的每次会话中一开始就会以更高效的方式工作。
Terse 会把我的 Claude Code 提示词发送到别处吗?
不会。Terse 100% 在本机运行。它通过 macOS 辅助功能 API 读取文本,用 Rust 引擎在本地压缩,再写回终端。你的代码和提示词永远不会离开你的电脑。
什么是重复工具调用?
重复工具调用是指 Claude Code 多次读取同一个文件,或把同一次搜索跑了两遍。每次调用都要为调用本身和进入上下文的结果付出 token。Terse 的 Agent 监控器会实时标记这些行为,让你在成本累积之前及时打断。
不用 Terse 的话,一次 Claude Code 会话要花多少钱?
一次典型的 2 小时 Claude Opus 会话会产生约 210,000 个 token 的 CLI 噪音。按每百万 token 15–75 美元计算,单次会话就是 3–15 美元。重度用户每月要花 200–500 美元。Terse 可将其压缩 40–89%。
