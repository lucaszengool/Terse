Speed Up Mode

One switch turns on the three levers that make agents respond faster: cache-safe trimming, a local result cache, and tool-result compression.

⚡
Cache-safe trimming
Only the newest turn is ever rewritten, so the model's prompt cache stays warm — up to ~80% faster time-to-first-token on long sessions.
♻️
Local result cache
Exact-repeat tool calls (same file read twice, same search) are served instantly from disk instead of burning tokens again.
🗜
Tool-result compression
Verbose tool output is compacted before it enters context — a smaller context decodes faster on every following turn.
诚实的代价 · The honest tradeoffs
  • Less total token reduction. Cache-safe trimming skips history rewrites, so raw token savings are smaller than Aggressive mode — you trade savings for speed.
  • Repeats can be stale. If a file changed between two identical reads, the local cache can serve the older result for that session. Terse invalidates on write, but external changes aren't seen.
  • Compression can drop rare detail. Compacted tool output keeps structure and key values, but an unusual detail deep in verbose output may be trimmed. Turn Speed Up off for forensic debugging sessions.
