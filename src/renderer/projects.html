Let Terse control the town

To steer Code Town with the arrow keys, WASD and drags on the desktop, macOS needs you to give Terse the Accessibility permission. Terse only uses it while “Control town” is on.
  1. Click Open System Settings below.
  2. In Accessibility, turn on the switch next to Terse.
  3. If Terse is already on the list but this window stays yellow, select Terse, click − to remove it, then click + and choose Terse in Applications. (Every Terse update needs this once.)
  4. Come back — this turns green and the town takes the keyboard by itself.
