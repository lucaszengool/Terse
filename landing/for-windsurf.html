Frequently Asked Questions

Everything about using Terse with Windsurf.

Does Terse work with Windsurf?
Yes. Windsurf is a VS Code–based AI IDE, so Terse attaches to the Cascade chat input the same way it does for Cursor and Copilot. Focus Windsurf and a floating Terse bar appears, compresses the instruction you type into Cascade, and tracks the per-request token count. Detection is automatic — no configuration.
Why does Cascade use so many credits/tokens?
Cascade is flow-aware: every request bundles your open files, retrieved codebase context, conversation history, and terminal output into the prompt. A single flow action can be tens of thousands of tokens, and Windsurf bills credits against that. Terse can't shrink the auto-added context, but it compresses your typed instruction 40–70% and surfaces the per-request cost.
Does Terse read my Windsurf code?
No. Terse only reads the text you type into the Cascade input, via macOS Accessibility APIs, and compresses it on-device. It does not read your source files, Windsurf's codebase index, or Cascade's internal API traffic. Nothing you type or open ever leaves your machine.
Which models does it track?
Whatever you pick in Cascade — Claude Sonnet 4.5, Opus 4, GPT-4o, Gemini 2.5 Pro, Claude Haiku 4.5, or Windsurf's own SWE-1 / Cascade Base. Terse applies the correct per-million rate to each request so the estimated cost matches your real usage.
