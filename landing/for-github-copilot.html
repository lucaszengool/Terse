Frequently Asked Questions

Everything about using Terse with GitHub Copilot.

Does Terse work with GitHub Copilot?
Yes. Terse detects VS Code via macOS Accessibility APIs and compresses prompts you type in the Copilot Chat panel and inline chat. It works automatically — no configuration required.
Does Terse work with Copilot CLI?
Yes. Terse monitors terminal sessions and can compress prompts sent to Copilot CLI workflows. The Agent Monitor tracks per-turn token usage and flags redundant queries across CLI interactions.
Will Terse affect Copilot's code completion quality?
No. Terse only compresses the natural language text you type — questions, instructions, context descriptions. Code blocks are always protected and pass through unchanged. The meaning of your prompt is preserved while the redundant language is removed.
Does Terse send my Copilot prompts to any server?
No. Terse is 100% on-device. It reads text via macOS Accessibility APIs, compresses locally using a Rust engine, and writes the compressed text back. Your code and prompts never leave your machine.
