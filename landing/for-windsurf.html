Frequently Asked Questions

Everything about using Terse with Windsurf.

How does Terse detect Windsurf?
Via process and configuration detection — one of 8 agents recognized out of the box, no Windsurf settings changes. Sessions appear in the monitor with token usage, estimated cost, burn rate, and history.
Does Terse compress prompts I type into Cascade?
Yes — the 35+ technique pipeline runs in Light, Balanced, or Aggressive mode on your Cascade prompts, with code blocks, paths, and identifiers always protected. Typical reduction is 40–70%.
Can Terse manage Windsurf's MCP servers?
Yes. The MCP Manager scans Windsurf's MCP config alongside Claude Code and Cursor, risk-scores every server, and enables or disables any of them with one click — no JSON editing.
Can I set a spending limit for Windsurf?
Yes. Set a burn-rate, token, or dollar ceiling in the budget circuit breaker. On breach, Terse escalates alert → SIGSTOP pause → SIGTERM kill before the next API call, with one-click resume.
Is Windsurf monitoring as deep as Claude Code?
No — Claude Code gets exact tokens, cache efficiency, and 30-day backfill via JSONL streaming. Windsurf gets process/config detection with session-level stats. Optimizer, MCP Manager, Doctor, and breaker work fully for both.
Does any Windsurf data leave my machine?
No. Detection, monitoring, compression, MCP scanning, and budget enforcement all run on-device on macOS or Windows.
