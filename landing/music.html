From Now Playing to your wallpaper

Three steps, all on your machine. The only network request is fetching a song's lyrics the first time it plays.

1

Recognise the song

Terse reads the system's Now Playing: title, artist, album, length and position. Pause, skip or scrub and it follows.

2

Find the synced lyrics

A .lrc file next to the song, lyrics embedded in the file, LRCLIB's free synced-lyrics library, then NetEase Cloud Music — matched by song length and cached locally.

3

Build each line from particles

Every line assembles out of the field, a highlight sweeps across it while it is sung, and it scatters into the next one.

Questions, answered

How do I show song lyrics on my Mac desktop?
Install Terse, open Music in the sidebar and switch on “Put lyrics on the wallpaper”. Terse picks up whatever is playing from the system’s Now Playing, fetches the song’s synced lyrics and draws each line as particles on your wallpaper, in time with the music.
Which music apps does it work with?
Any player that reports to the system’s Now Playing — Apple Music, Spotify, NetEase Cloud Music and most others. Terse only needs the title, artist, album, length and playback position that the player already publishes.
Where do the lyrics come from?
In order: a .lrc file next to the song, lyrics embedded in the song file (for local files played in the Music app), LRCLIB’s free synced-lyrics library, then NetEase Cloud Music’s public lyrics. Results are matched by song length and cached on your machine, so each song is fetched only once.
Does Terse record audio or use the microphone?
No. Music mode reads Now Playing metadata only. It never records audio, never uses the microphone and never asks for screen-recording permission.
Are the lyrics word-by-word, like karaoke?
Not quite. Synced lyrics (LRC) are timed per line, so Terse sweeps the highlight across each line over that line’s duration. It follows the song closely, but it is an interpolation, not true per-word timing.
Is music mode free?
Yes. Music mode is free with the default look. Pro lets the lyrics float above every window and adds 15 appearance controls: density, particle size, lyric glow, beat glow, light motes, mote speed, text size, weight, letter spacing, horizontal and vertical position, edge fade, animation, lyric colour and highlight colour.
Can I keep my wallpaper and agent text while lyrics play?
Yes. Lyrics are drawn on their own layer, so your particle wallpaper, notifications and coding-agent text keep playing underneath. If you float the lyrics above all windows on top of an opaque engine, Terse lifts only the lyrics so the screen is never covered.
Does music mode work on Windows?
Music mode has been ported to the Windows app and arrives with version 1.4.1, which is in Microsoft Store review now. It is available in the macOS app today.
