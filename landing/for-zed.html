Frequently Asked Questions

Everything about using Terse with Zed.

Does Terse work with Zed?
Yes. Terse reads the text you type into Zed's AI assistant and agent panel via macOS Accessibility APIs (and Windows UI Automation). A floating bar auto-appears when you focus Zed, showing live token counts and the compressed version of your prompt. It works on your typed instructions — not on Zed's internal AI traffic.
Why do Zed AI requests use tokens and credits?
Every agent request sends your instruction plus code context, thread history, and a system prompt to a hosted model. On Zed Pro you get $5/mo of token credits and then pay by usage — so shorter, denser prompts directly stretch your credits. Terse compresses the editable part by 40–70%.
Does Terse read my Zed code?
No. Terse only reads the natural-language prompt you type into the AI panel, and processes it entirely on-device. It never reads your source files, your project, or Zed's internal context, and nothing is sent to a Terse server.
Which models does Terse track?
Claude Opus 4, Claude Sonnet 4.5, Claude Haiku 4.5, GPT-5.x, GPT-4o, and Gemini 2.5 Pro — including Zed's hosted models. Terse is model-aware and prices each prompt with the real per-million rate of whichever model your thread has selected.
Will Terse break my Zed prompts?
No. In Soft and Normal modes, meaning is fully preserved — only filler, hedging, and typos are removed. Code blocks, file paths, and technical terms are always protected. You can preview the compressed version before applying, or use Aggressive mode when you want maximum compression.
Is there a free trial?
Yes — both Pro ($4.99/mo) and Premium ($99/mo) include a 30-day free trial. No credit card charge until your trial ends. Cancel anytime.
